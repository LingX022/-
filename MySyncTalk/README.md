# MySyncTalk

## 简介
本项目基于 SyncTalk 系统框架，实现了一个面向实时对话场景的语音克隆模块。
该模块负责在用户输入文本或对话内容后，生成目标说话人风格的语音结果，
并通过后端接口与前端系统进行对接，为 Talking Face Generation 模型提供语音驱动输入。

本项目重点在于语音克隆推理流程的封装、服务化接口设计以及与现有系统的集成，
而非 Talking Face 模型本体的复现。


## 目录结构
- inference.py：模型推理代码
- service.py：后端服务接口
- README.md：说明文档

## 使用说明
1. 系统前端提交音频请求
2. 后端调用 service.py 中的 handle_request
3. inference.py 执行模型推理并返回生成结果路径
